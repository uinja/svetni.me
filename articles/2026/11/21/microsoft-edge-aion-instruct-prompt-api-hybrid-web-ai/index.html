Microsoft Edge въвежда локалния модел Aion Instruct, Prompt API и експериментален Decisions API за хибриден уеб ИИ

Публикувано от Svetni.me Editorial на 21 ноември 2026 г. в Изкуствен интелект


Източник: Microsoft Edge Developer Blog / Демонстрация на локалния модел Aion Instruct и Prompt API в Microsoft Edge

В официално съобщение в блога за разработчици на Windows и Edge софтуерният инженер Сохум Чатърджи обяви три ключови технологични обновления, които превръщат браузъра Microsoft Edge в пълноценна платформа за хибриден изкуствен интелект в уеб среда [1]. Компанията пуска в обща наличност новия компактен модел с отворени тегла Aion Instruct, стартира публичен Origin Trial за браузърния интерфейс Prompt API за реални продукционни уебсайтове и представя ранна версия за разработчици на експерименталния Decisions API за бързо структурирано оценяване на текст без генеративен овърхед [1].

Aion Instruct с 2.3 милиарда параметри заменя Phi-4-mini като вграден браузърен модел

След успешното приключване на предварителните тестове с версията Aion-1.0-Instruct и интегрирането на обратната връзка от ранните внедрители, финалният модел Aion Instruct вече е достъпен с отворени тегла в платформата Hugging Face и поема ролята на стандартен вграден модел в Microsoft Edge, заменяйки досегашния Phi-4-mini [1]. По-късно през годината моделът ще бъде интегриран на системно ниво и в операционната система Windows, разширявайки локалните ИИ възможности върху стандартни компютри и Copilot+ PC устройства.

С архитектура от едва 2.3 милиарда параметри Aion Instruct представлява ново поколение малки езикови модели (SLM), което е значително по-компактно, по-бързо и съвместимо с много по-широк спектър от потребителски хардуер спрямо фамилията Phi [1]. Въпреки намаления размер моделът запазва съпоставимо качество при ключови уеб задачи като синтез и генериране на текст, обобщаване, стриктно следване на инструкции и извеждане на структурирани данни. За да се гарантира оптимално управление на системните ресурси, Edge изтегля Aion Instruct само при първо реално извикване от уебсайт или браузърна функция и единствено върху устройства с достатъчен хардуерен капацитет, като потребителите разполагат с пълен контрол да деактивират локалния ИИ от настройките, което незабавно изтрива модела от диска и блокира бъдещи изтегляния [1].

Origin Trial за Prompt API и еднопасово вероятностно оценяване чрез Decisions API

До момента интерфейсът Prompt API беше ограничен само до тестовите канали Edge Canary и Dev, но с новия Origin Trial уеб разработчиците вече могат да активират локален браузърен инференс директно върху своите живи продукционни сайтове [1]. Тази фаза позволява изпробване на функции за локална текстова асистенция и обобщаване (заедно със Summarizer API) в реални потребителски условия, като събраните данни за производителността и оперативната съвместимост между различните модели ще послужат за стандартизацията на интерфейса съвместно с останалите производители на браузъри и уеб общността [1].

Паралелно с това Microsoft представя в каналите Edge Canary и Dev експерименталния интерфейс Decisions API, задвижван локално от Aion Instruct и базиран на отворената спецификация за браузърни решения [1] [2]. Чрез извикване на DecisionModel.create() и model.decide() в няколко реда клиентски JavaScript код уеб приложенията могат да задават едновременно въпроси за множествен избор (choice), числови оценки по скала от 1 до 5 (score) и булеви проверки Да/Не (boolean) върху даден текст (например потребителско ревю в електронен магазин), получавайки обратно точни вероятности и коефициент на увереност (confidence), изчислени в един-единствен проход на модела без никакво генериране на текст [1].


Инфографика: Ключови стълбове и анализ

Системни архитектурни и макроикономически последици: Уеб браузърът като универсален хибриден ИИ рънтайм

Интегрирането на 2.3-милиардния модел Aion Instruct заедно със стандартизираните интерфейси Prompt API и Decisions API в Microsoft Edge трансформира ролята на уеб браузъра от пасивен рендериращ клиент в управлявана среда за изпълнение на невронни мрежи. В продължение на десетилетия уеб разработчиците бяха принудени или да изпращат всяка текстова операция към скъпи облачни сървъри, или да пакетират собствени тежки WebAssembly/WebGPU модели за всеки отделен сайт. Предоставянето на един споделен, управляван от браузъра локален модел елиминира дублираното изтегляне на гигабайти тегла и осигурява мигновен достъп до локален инференс през стандартен JavaScript.

От архитектурна гледна точка концепцията за хибриден изкуствен интелект решава фундаменталната дилема между латентност, поверителност и изчислителна мощ. Чрез локалното изпълнение на Decisions API и Prompt API уеб приложенията могат да извършват триаж на потребителското намерение, филтриране, сортиране и предварително обобщаване директно върху клиентското устройство с нулева мрежова латентност и без данните да напускат браузъра. Само когато задачата надхвърли капацитета на 2.3B модела или устройството не поддържа локален ИИ, приложението пренасочва заявката към конфигуриран облачен доставчик.

В макроикономически план тази хибридна архитектура драстично променя структурата на разходите за уеб базираните SaaS компании. Прехвърлянето на милиарди рутинни операции за класификация, скоринг и текстова обработка от облачните API сървъри към локалните GPU и NPU ускорители на крайните потребители премахва променливия разход за токени при базовите интерактивни функции, демократизирайки достъпа до интелигентни уеб интерфейси дори за малки независими разработчици.
