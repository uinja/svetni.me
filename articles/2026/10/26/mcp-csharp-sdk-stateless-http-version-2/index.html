Официалният MCP C# SDK 2.0 преминава към безсъстояние по HTTP и добавя многоходови заявки

Публикувано от Svetni.me Editorial на 26 октомври 2026 г. в Изкуствен интелект


Източник: InfoQ

Корпорацията Microsoft обяви официалното пускане на версия 2.0 на официалния софтуерен пакет за разработка (SDK) за C# на протокола за модел контекст (Model Context Protocol) [1]. Новата версия въвежда фундаментални архитектурни промени, включително преминаване към напълно безсъстояние (Stateless) при HTTP комуникация и поддръжка на многоходови транзакции в рамките на една сесия.

Безсъстояние по HTTP и елиминиране на лепнещите сесии

В първоначалната реализация на MCP поддържането на постоянни SSE (Server-Sent Events) връзки изискваше съхраняване на състоянието на агента в паметта на конкретния бекенд сървър. Това създаваше огромни трудности при хоризонтално мащабиране в облачни среди като Kubernetes и Azure Container Apps, налагайки използване на тромави 'sticky sessions'.

С версия 2.0 всяка входяща HTTP заявка пренася необходимия криптографски токен за контекст в заглавната част, което позволява заявките на един и същ агент да се обслужват от различни бекенд инстанции без загуба на данни. Това отключва пълния потенциал на сървърлес архитектурите за изпълнение на MCP инструменти.

Многоходови заявки и асинхронно потвърждение

Другото ключово подобрение е въвеждането на многоходови диалози (Multi Round-Trip Requests) директно на протоколно ниво. Вместо да изчаква пълен цикъл за всяко извикване на инструмент, сървърът може да изпраща междинни въпроси за потвърждение към клиента преди да изпълни критични операции.

Утвърждаване на MCP като универсален промишлен стандарт

Пускането на версия 2.0 на C# SDK бележи окончателното интегриране на Model Context Protocol в корпоративния стек на .NET. За милионите корпоративни разработчици, поддържащи съществуващи бекенд системи на C#, това предоставя директен и сертифициран път за превръщане на вътрешните бази данни и микроуслуги в стандартизирани инструменти за изкуствен интелект.

Премахването на състоянието превръща MCP в зрял протокол, готов да поеме натоварвания от милиарди транзакции дневно, циментирайки ролята му на де факто стандарт за свързване на модели с корпоративни ресурси.
