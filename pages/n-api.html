Node-API (N-API)

Node-API (по-рано известно като N-API) е стабилен приложно-програмен интерфейс (API) на C за създаване на нативни разширения за Node.js, независим от вътрешната версия на JavaScript двигателя V8.

Значение при миграции към Rust

  • ABI стабилност: Позволява на нативните модули, написани на Rust или C++, да се компилират веднъж и да работят в различни версии на Node.js без прекомпилация.
  • Поетапно пренаписване: Служи като мост за постепенна подмяна на критични TypeScript компоненти с високопроизводителен Rust код.
  • Безопасност на паметта: Интеграция с инструменти като Neon за безопасно споделяне на памет между JavaScript и Rust.
