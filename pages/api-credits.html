API кредити и квоти (API Credits)

API кредитите са форма на предплатена или субсидирана изчислителна валута, използвана от платформите за облачен изкуствен интелект за остойностяване на заявките към техните модели на база обработени токени (input/output tokens) или време за изчисление.

Предоставянето на големи обеми безплатни API кредити е основна стратегия за разработване на екосистеми от технологични доставчици, целяща бързо привличане на софтуерни инженери и формиране на дългосрочна зависимост (platform lock-in) към техните проприетарни модели.
