GitHub Copilot SDK

GitHub Copilot SDK е програмен комплект за разработка, предоставен от Microsoft и GitHub, който позволява на софтуерните инженери да интегрират когнитивните възможности на Copilot директно в собствени корпоративни инструменти и бекенд услуги.

SDK поддържа парадигмата Bring Your Own Model (BYOM), осигурявайки свързване с вътрешни модели, разположени в частни облаци, без изтичане на чувствителен код към външни доставчици.
