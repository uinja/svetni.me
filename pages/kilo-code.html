Kilo Code

Kilo Code е технологичен стартъп, който разработва цялостна платформа за агентно инженерство (agentic engineering), предназначена за софтуерни разработчици. Компанията се фокусира върху практическата интеграция на ИИ агенти в ежедневния работен процес на инженерните екипи, с цел превръщане на инвестициите в изкуствен интелект в реални софтуерни продукти. Kilo Code популяризира подхода на разделяне на задачите между различни по сложност модели и измерването на възвръщаемостта на инвестициите чрез метрики като „цена за pull request“ (cost per PR).
