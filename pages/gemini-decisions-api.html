Gemini Decisions API

Gemini Decisions API е специализиран програмен интерфейс на Google, задвижван от модела gemini-decision-1, който заменя свободното генериране на текст и парсването на JSON с директно, еднопасово оценяване на предварително дефинирани въпроси.

Архитектура и икономически модел

  • Три типа структурирани решения: Поддържа бинарни въпроси Да/Не (noul), избор измежду списък с опции (choice) и оценяване по градирана скала (score), връщайки калибрирани вероятности и коефициент на увереност (confidence).
  • Масова паралелна обработка: Позволява оценяване на до 1000 независими въпроса върху един и същ мултимодален вход (текст, изображения, аудио, видео, PDF) в една заявка при цена от $0.10 за милион входни токена и $0 за изходни токени.

Споменавания в статии
