React Native

React Native е популярна рамка за разработка на мобилни приложения с отворен код, първоначално създадена от Meta. Тя позволява на разработчиците да изграждат нативни приложения за iOS и Android, използвайки JavaScript или TypeScript и декларативния компонентен модел на React. Вместо каскадни стилови таблици (CSS), React Native разчита на вградени стилови обекти и независим модел за разположение на компонентите (Flexbox), оптимизиран за мобилни операционни системи.
