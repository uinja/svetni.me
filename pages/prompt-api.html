Prompt API

Prompt API е стандартизиран браузърен JavaScript интерфейс, който позволява на уеб приложенията да извикват локално вградени малки езикови модели (като Aion Instruct в Microsoft Edge) директно от клиентския код.

Роля в хибридния уеб ИИ

  • Локален инференс с нулева сървърна цена: Изпълнява задачи за генериране на текст, обобщаване и структурирани отговори върху устройството на потребителя с висока поверителност.
  • Стандартизация и Origin Trial: Преминава през публичен Origin Trial в Microsoft Edge за събиране на телеметрия и оперативна съвместимост между различните браузърни енджини.

Споменавания в статии

  • Microsoft Edge въвежда локалния модел Aion Instruct, Prompt API и експериментален Decisions API за хибриден уеб ИИ
