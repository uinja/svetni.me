AWS Agent Registry

AWS Agent Registry е управляван регистър (в публична тестова версия), предоставен от Amazon Web Services за откриване, управление и управление на жизнения цикъл (governance) на AI агенти, инструменти и умения в организацията. Услугата съответства на спецификацията за карти на агенти (A2A agent cards) и инструменталната схема на протокола MCP (Model Context Protocol). Тя предоставя механизъм за преглед и одобрение на агенти преди тяхното публикуване в производствена среда, с цел ограничаване на неконтролираното разрастване на агенти (agent sprawl).
