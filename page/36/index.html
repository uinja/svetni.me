Снимка: AWS Labs / GitHub

Изследователското подразделение AWS Labs на облачния гигант Amazon Web Services (AWS) публикува официално проекта с отворен код Aidlc (AI Development Lifecycle) — иновативна инженерна рамка за дефиниране на декларативни правила и адаптивно управление на агентни работни процеси (Agentic Workflows) при софтуерна разработка [1].
