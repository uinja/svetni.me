Какво разкрива анализът на 25 трилиона токена за реалното внедряване на AI агенти от разработчиците


Снимка: InfoQ / Brendan O'Leary

В рамките на авторитетната технологична конференция за софтуерна архитектура InfoQ, изследователят и индустриален ветеран Брендън О'Лиъри представи най-мащабното емпирично проучване върху практическото внедряване на AI агенти в разработката, базирано на телеметрични данни от над 25 трилиона обработени токена [1]. AWS Aidlc: Декларативни правила и адаптивни работни процеси за контрол на кодиращи AI агенти


Снимка: AWS Labs / GitHub

Изследователското подразделение AWS Labs на облачния гигант Amazon Web Services (AWS) публикува официално проекта с отворен код Aidlc (AI Development Lifecycle) — иновативна инженерна рамка за дефиниране на декларативни правила и адаптивно управление на агентни работни процеси (Agentic Workflows) при софтуерна разработка [1]. Инструментът адресира един от най-разочароващите проблеми за софтуерните екипи: склонността на автономните програмисти да се отклоняват от първоначалната задача, пренаписвайки цели кодови хранилища без нужда.

В знаков стратегически ход за цялата софтуерна индустрия, европейският технологичен лидер JetBrains обяви официалното пускане на версия 1.0 на своя самостоятелен езиков енджин за Java и Kotlin, съвместим с водещите нови редактори за програмиране Cursor и Visual Studio Code [1].
