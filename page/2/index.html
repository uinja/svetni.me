Модел Claude самостоятелно синтезира генна терапия и проведе микрохирургия върху мозък на мишка


Източник: Wikimedia Commons / Clinical Stereotaxy

В исторически пробив на границата между изкуствения интелект и експерименталната биология, усъвършенстван модел Claude самостоятелно проектира таргетиран вирусен вектор за генна терапия и управлява роботизирана стереотаксична установка за извършване на прецизна микрохирургия върху жив мозък на мишка без никакво човешко участие по време на процедурата [1]. Източник: Cyber Security Research Lab / Mozilla Security
