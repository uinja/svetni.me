Уязвимостта от нулев ден SignDrop в Windows позволява придобиване на права SYSTEM


Източник: BleepingComputer / Trend Micro

Експерти по информационна сигурност идентифицираха активна експлоатация на нова уязвимост от нулев ден (zero-day), обозначена като SignDrop, в ядрото на операционната система Windows на Microsoft [1].
